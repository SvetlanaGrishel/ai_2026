# Sauce Demo Automated Tests

This project contains automated tests for the Sauce Demo application. It includes both UI and API tests.

## UI Functionality and Pages

The UI tests cover the following key functionalities and interactions with the web application:

-   **Login Page**: Tests user authentication, including successful login with valid credentials.
-   **Product Page**: Tests displaying products, sorting options, and viewing product details.
-   **Add to Cart**: Tests the ability to add products to the shopping cart.
-   **Cart Management**: Tests managing items within the shopping cart, such as updating quantities or removing items.
-   **Checkout Process**: Tests the entire checkout flow, from providing shipping information to completing the purchase.

## API Functionality and Pages

The API tests interact with the application's backend services and cover the following functionalities:

-   **Login API (`LoginApi.java`)**: Handles user authentication and retrieves authentication tokens.
-   **Product API (`ProductApi.java`)**: Provides endpoints for fetching product lists and individual product details.
-   **Cart API (`CartApi.java`)**: Manages the shopping cart, including adding, updating, and removing items via API calls.
-   **Checkout API (`CheckoutApi.java`)**: Facilitates the checkout process through backend API interactions.

## Project Structure

- `pom.xml`: Maven project configuration file. It manages dependencies and build settings.
- `src/main/java`: This directory is intended for the main application source code.
- `src/test/java`: This directory contains all the test source code.
    - `com.saucedemo.base`: Contains the base test class for setting up and tearing down the WebDriver for UI tests.
    - `com.saucedemo.tests`: Contains the UI test classes.
    - `com.saucedemo.api_tests`: Contains the API test classes.
    - `com.saucedemo.api_pages`: Contains page objects for the API tests, encapsulating the logic for interacting with the API endpoints.
- `src/test/resources`: This directory holds test-related resources.
    - `testng.xml`: The TestNG suite file for running all tests.
    - `testng-api.xml`: The TestNG suite file for running only the API tests.
- `allure-results`: This directory stores the raw test results generated by Allure.
- `allure-report`: This directory contains the generated Allure HTML report.
- `.allure`: This directory contains the Allure command-line tool.

## How to Run Tests

### UI Tests

To run the UI tests, execute the following Maven command:

```bash
mvn clean test
```

### API Tests

To run the API tests, you first need to configure the correct API base URI. Open the `src/test/java/com/saucedemo/api_pages/ApiConfig.java` file and replace the placeholder with the actual base URI.

Once the base URI is configured, run the following Maven command:

```bash
mvn clean test -Dsurefire.suiteXmlFiles=src/test/resources/testng-api.xml
```

## How to Generate the Allure Report

After running the tests, you can generate the Allure report using the following command:

```bash
./.allure/allure-2.17.2/bin/allure generate allure-results --clean -o allure-report
```

To view the report, open the `index.html` file in the `allure-report` directory in your web browser.
